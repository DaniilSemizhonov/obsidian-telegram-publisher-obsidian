# Telegram Publisher для Obsidian

Плагин для настольного Obsidian 1.11.4 и новее. Разбирает активную Markdown-заметку через сервер Telegram Publisher, показывает время и состав публикаций и после подтверждения ставит их в нативную отложку Telegram. Для работы нужен запущенный сервер Telegram Publisher с авторизованным worker и разрешённым каналом.

## Установка через BRAT

1. В Obsidian откройте **Settings → Community plugins → Browse**, установите и включите **Obsidian42 - BRAT**.
2. В настройках BRAT нажмите **Add Beta Plugin** и укажите `https://github.com/DaniilSemizhonov/obsidian-telegram-publisher-obsidian`.
3. Выберите последнюю версию, установите и включите **Telegram Publisher**.
4. В настройках **Telegram Publisher** задайте адрес сервера и сохраните токен `BACKEND_API_TOKEN`. Плагин хранит токен в хранилище секретов Obsidian.

Если API на VPS слушает `127.0.0.1:8000`, откройте SSH-туннель на компьютере с Obsidian. Подставьте свои логин и адрес VPS:

```sh
ssh -N -L 127.0.0.1:8000:127.0.0.1:8000 user@vps
```

Пока терминал с туннелем открыт, в плагине используйте `http://127.0.0.1:8000`. Если API опубликован через HTTPS, укажите его HTTPS-адрес.

## Первый тест

1. Нажмите **Проверка подключения → Проверить**. Плагин должен показать, что Telegram авторизован и найден хотя бы один разрешённый канал.
2. Создайте заметку с примером ниже и дождитесь её сохранения. Запустите **Telegram: Предпросмотр викторин** из палитры команд.
3. Выберите отдельный тестовый канал и время минимум на 15 минут вперёд, чтобы успеть проверить результат. Нажмите **Обновить предпросмотр**, затем **Поставить в отложку** и подтвердите канал и число сообщений.
4. Дождитесь **Подтверждено в отложке** и ID сообщения. Через **Telegram: Открыть отложку канала** можно посмотреть снимок очереди Telegram. Если публикация была нужна только для теста, удалите её из отложки в приложении Telegram до назначенного времени.

```markdown
## 1. Сколько бит содержится в байте?

- [ ] 4
- [x] 8
- [ ] 16
- [ ] 32

**Пояснение:** В одном байте восемь бит.
```

Каждое задание начинается с заголовка `##`. Идентификаторы в заметках не нужны. К заданию можно добавить один блок кода с языком, например `python`, или одно локальное изображение PNG, JPEG или WebP через `![[image.png]]` либо обычную Markdown-ссылку. В заметке можно задать параметры через YAML-ключ `telegram`. Плагин отправляет содержимое активной заметки на указанный сервер при проверке или предпросмотре. Статус сохраняется для последних 100 подборок этого хранилища.

## Управление отложкой

Запустите **Telegram: Открыть отложку канала**. В разделе **В отложке** можно удалить созданное через плагин задание вместе с его картинкой. В разделе **Опубликованы** видны викторины среди последних 100 сообщений канала.

Если вы удалили будущие сообщения прямо в Telegram, нажмите **Сверить с Telegram**. После сверки можно исправить ту же заметку и снова запланировать задание. Если у задания осталось второе сообщение, удалите его из отложки отдельно или кнопкой в панели. Для этой панели нужен обновлённый сервер.

## Локальная сборка

Требуется Node.js 24.

```sh
npm ci
npm run check
npm test
npm run build
```

Сборка создаёт `dist/main.js`. Для релиза BRAT загрузите `dist/main.js`, `manifest.json` и `styles.css` как три отдельных файла. Тег релиза должен совпадать с версией в `manifest.json`.
