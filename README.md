# Telegram Publisher для Obsidian

Плагин для Obsidian 1.11.4 и новее на компьютере, iPhone/iPad и Android. Разбирает активную Markdown-заметку через сервер Telegram Publisher, показывает время и состав публикаций и после подтверждения ставит их в нативную отложку Telegram. Для работы нужен запущенный сервер Telegram Publisher с авторизованным worker и разрешённым каналом.

## Установка через BRAT

1. В Obsidian откройте **Settings → Community plugins → Browse**, установите и включите **Obsidian42 - BRAT**.
2. В настройках BRAT нажмите **Add Beta Plugin** и укажите `https://github.com/DaniilSemizhonov/obsidian-telegram-publisher-obsidian`.
3. Выберите последнюю версию, установите и включите **Telegram Publisher**.
4. В настройках **Telegram Publisher** задайте адрес сервера и сохраните токен `BACKEND_API_TOKEN`. Плагин хранит токен в хранилище секретов Obsidian.

Если API на VPS слушает `127.0.0.1:8000`, откройте SSH-туннель на компьютере с Obsidian. Подставьте свои логин и адрес VPS:

```sh
ssh -N -L 127.0.0.1:8000:127.0.0.1:8000 user@vps
```

Пока терминал с туннелем открыт, в плагине используйте `http://127.0.0.1:8000`. Если API опубликован через HTTPS, укажите его HTTPS-адрес.

## Первый тест

1. Нажмите **Проверка подключения → Проверить**. Плагин должен показать, что Telegram авторизован и найден хотя бы один разрешённый канал.
2. Создайте заметку с примером ниже и дождитесь её сохранения. Запустите **Telegram: Запланировать подборку** из палитры команд.
3. Выберите отдельный тестовый канал и время минимум на 15 минут вперёд, чтобы успеть проверить результат. Нажмите **Обновить предпросмотр**, затем **Поставить в отложку** и подтвердите канал и число сообщений.
4. Дождитесь **Подтверждено в отложке** и ID сообщения. Через **Telegram: Открыть отложку канала** можно посмотреть снимок очереди Telegram. Если публикация была нужна только для теста, удалите её из отложки в приложении Telegram до назначенного времени.

```markdown
## 1. Сколько бит содержится в байте?

- [ ] 4
- [x] 8
- [ ] 16
- [ ] 32

**Пояснение:** В одном байте восемь бит.
```

Каждое задание начинается с заголовка `##`. Идентификаторы в заметках не нужны. К заданию можно добавить один блок кода с языком, например `python`, или одно локальное изображение PNG, JPEG или WebP через `![[image.png]]` либо обычную Markdown-ссылку. В заметке можно задать параметры через YAML-ключ `telegram`. Плагин отправляет содержимое активной заметки на указанный сервер при проверке или предпросмотре. Статус сохраняется для последних 100 подборок этого хранилища.

## Управление отложкой

Нажмите значок календаря на левой панели Obsidian или вызовите **Telegram: Открыть отложку канала**. Справа откроется панель со списком отложенных сообщений выбранного канала.

- **Новый пост** открывает форму для обычного текстового сообщения. Введите текст, дату и время в часовом поясе из настроек плагина и нажмите **Поставить в отложку**. После подтверждения Telegram пост появится в списке с назначенным временем.
- **Викторины из заметки** открывает предпросмотр подборки из текущей Markdown-заметки. Выберите **Подписи к изображениям → Над изображением**, чтобы заголовки всех заданий с картинками, включая изображения с кодом, появились над ними в Telegram.
- **Минус ошибка** открывает предпросмотр задач из раздела `## Минус ошибка` активной заметки. Каждая задача начинается с заголовка `###` и содержит условие и один блок кода. Плагин готовит по одному посту на задачу с картинкой кода и условием под ней. Если в условии есть Markdown-таблица, весь пост отправляется как Telegram Rich Message со встроенной картинкой и нативной таблицей. Укажите дату, время и интервал между постами. Для рубрики нужно обновить плагин, API, worker и рендерер.
- **Изменить викторину** позволяет исправить вопрос, варианты, правильный ответ и пояснение у запланированной через плагин викторины. Новая викторина остаётся в том же временном слоте.
- **Удалить из отложки** удаляет созданный через плагин пост или задание вместе с отложенной картинкой. В разделе **Опубликованы** видны викторины среди последних 100 сообщений канала.

Если вы удалили будущие сообщения прямо в Telegram, нажмите **Сверить с Telegram**. После сверки можно исправить ту же заметку и снова запланировать задание. Если у задания осталось второе сообщение, удалите его из отложки отдельно или кнопкой в панели. Для текстовых постов обновите и API, и worker.

В настройках или при предпросмотре можно выбрать тему **Коралловая** для изображений с кодом.

## Локальная сборка

Требуется Node.js 24.

```sh
npm ci
npm run check
npm test
npm run build
```

Сборка создаёт `dist/main.js`. Для релиза BRAT загрузите `dist/main.js`, `manifest.json` и `styles.css` как три отдельных файла. Тег релиза должен совпадать с версией в `manifest.json`.

## Викторина из обычной рабочей заметки

В разделах «Викторина…», «Правки» или «Текст поста» плагин распознаёт вопросы с нумерацией `**1.**` / `1.`, варианты `а)` / `a)` и правильный ответ с `✅`. Пояснение начинается с `Пояснение:`. Переформатировать заметку в чекбоксы не нужно. Старый формат с `##` и чекбоксами продолжает работать.

Вопросом становится последний абзац с вопросительным знаком; если его нет — последний абзац перед вариантами. Остальные абзацы становятся отдельным постом с условием. Поддерживаются экранированные номера `1\.` и пояснения вида `**Пояснение.**`. Заголовок темы внутри раздела «Текст поста» не прерывает распознавание. Текст раздела «Текст поста» добавляется перед первым условием. YAML, цитаты (включая подсказки), служебные разделы и чеклист «Перед отложкой» не публикуются. Не помещайте предназначенный для публикации текст в цитаты или блоки кода в этом формате; для заданий с кодом и изображениями используйте прежний формат.

В режиме редактирования строки подсвечиваются: синим — отдельный пост, фиолетовым — вопрос и варианты, зелёным — пояснение. В окне планирования откройте «Состав публикации»: здесь можно изменить условие, вопрос, варианты, правильный ответ и пояснение без изменения заметки. Счётчики показывают ограничения Telegram; длинные пояснения не обрезаются, их нужно сократить вручную. После изменения состава обновите предпросмотр.

Канал подставляется из `channel`, если его название однозначно совпадает с доступным каналом; дата — из `publish_date`. Настройки `telegram` имеют приоритет. Время из ТЗ не угадывается: проверьте его в форме. Перед первым вопросом с условием публикуется отдельный текст, затем через заданную задержку — викторина. Они входят в одну подборку и удаляются вместе.

Для отдельного условия нужно обновить **плагин, API и worker** из одной версии исходников. Обновление только плагина недостаточно. Автоматическая подсветка работает в редакторе Obsidian, не в режиме чтения.


## На телефоне (версия 0.6.0)

1. Установите BRAT в мобильном Obsidian и добавьте тот же репозиторий плагина. Если плагин уже установлен, обновите его через BRAT.
2. В настройках плагина заполните **Сервер для телефона** доступным HTTPS-адресом вашего API. Если основной адрес уже HTTPS и доступен с телефона, отдельное поле можно оставить пустым. `127.0.0.1` и SSH-туннель компьютера не дают телефону доступ к серверу. Сервер за VPN должен быть доступен и с телефона; адрес всё равно должен использовать HTTPS.
3. Сохраните токен API на телефоне и нажмите **Проверить**. Токен хранится отдельно от обычных настроек; не рассчитывайте на его перенос вместе с заметками.
4. Откройте заметку и вызовите **Telegram: Запланировать подборку** из палитры команд или **Telegram: Запланировать заметку** из меню редактора. Команду можно добавить на мобильную панель инструментов средствами Obsidian.
5. Команда **Telegram: Открыть отложку канала** открывает отдельную вкладку на телефоне. Кнопка «Викторины из заметки» использует последнюю открытую Markdown-заметку; её путь показан в окне подготовки.

На узком экране поля идут в одну колонку, кнопки имеют увеличенную область нажатия, таблицы прокручиваются по горизонтали. Публикации выполняет сервер: после подтверждения постановки в отложку держать Obsidian открытым не нужно. Если закрыть приложение до подтверждения, проверьте статус публикации после возвращения.

Для этого обновления нужно обновить также API и worker. Работа на физическом iPhone/Android не проверялась; выполнены проверка типов, автоматические тесты, сборка для браузерного окружения и проверка окна планирования на ширине 320, 390 и 768 пикселей.

### Весь вопрос отдельным сообщением (0.6.2)

Добавьте перед вариантами строку `Викторина: Выберите правильный ответ` (также поддерживается `**Викторина:**`). Весь вопрос с условием выше этой строки уйдёт отдельным постом. Текст после «Викторина:» станет заголовком опроса, ниже останутся варианты и правильный ответ ✅. Пояснение по-прежнему задаётся после вариантов. В редакторе весь пост подсвечивается синим, строка викторины и варианты — фиолетовым. Без этой строки действует автоматическое определение вопроса.
